Privacy Policy

Last updated September 2026

1. Overview

CppShorts Autoposter is a personal tool operated by a single developer, connected to a single TikTok account that the developer owns. This policy explains the only data the tool touches.

2. Information accessed

Through TikTok's standard sign-in (OAuth), the tool receives:

  • Basic profile identifiers for the one connected account (open ID, display name)
  • An access token and refresh token scoped only to that account

No information is accessed about any other TikTok user, and the tool never requests access to any account beyond the developer's own.

3. How it's used

The access token is used only to authenticate requests to TikTok's Content Posting API, so the connected account's own videos can be published. Nothing collected is used for advertising, analytics, or any purpose beyond publishing.

4. Storage and sharing

Tokens are stored securely by the developer and are never shared, sold, or disclosed to any third party.

5. Retention and revocation

Tokens are kept only for as long as the tool is in active use. Disconnecting the app from TikTok's Manage apps settings immediately revokes them.

6. Children's privacy

This tool is not directed at children and does not knowingly collect information from anyone under 13.

7. Changes to this policy

This page may be updated occasionally. Changes take effect as soon as they're posted here.

8. Contact

Questions about this policy can be sent to your-email@example.com.
