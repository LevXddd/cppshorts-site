A small tool that posts my own C++ shorts to TikTok

CppShorts Autoposter connects one TikTok account — mine — to TikTok's official Content Posting API, so videos from my existing C++ tutorial pipeline can go up without a manual export-and-upload step each time.

What it does

Videos are produced ahead of time by a pipeline I already run for my YouTube Shorts channel. This tool authorizes access to a single TikTok account through TikTok's standard sign-in flow, then publishes each finished video to that account.

Who it's for

Just me. This isn't a public product, a service for other creators, or something you can sign up for — it's a personal automation script for one account.
